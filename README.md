# NovaAI

**A Personal Local AI Assistant Built with Python**

NovaAI is a personal AI assistant designed to run locally on your computer using Ollama and local language models.

## Features

- 💬 AI-powered chat
- 🧠 Long-term memory
- ⚡ Streaming AI responses
- 🖥️ Desktop application
- 🔒 Local AI processing
- 🐍 Built with Python

## Technologies

- Python
- CustomTkinter
- Ollama
- Qwen3

## Requirements

- Windows 10/11
- Python 3.12 or newer
- Ollama
- Qwen3 model

## Installation

1. Install Python.
2. Install Ollama.
3. Download the Qwen3 model:

```bash
ollama pull qwen3:8b
```

4. Clone this repository:


git clone https://github.com/YOUR_USERNAME/NovaAI.git


5. Open the project folder:


cd NovaAI


6. Install dependencies:


pip install customtkinter requests


7. Run NovaAI:


py main.py
